# Robot Framework Automation Project

## Description
Automated web testing for nopCommerce e-commerce website
using Robot Framework and Selenium.

## Technologies Used
- Robot Framework
- SeleniumLibrary
- Python 3.14
- Chrome WebDriver

## Test Cases
- Login Test - Automated login functionality

## How To Run
pip install robotframework
pip install robotframework-seleniumlibrary
robot TestCases/TC1.robot

## Project Structure
RobotFrameWork_Automation/
├── TestCases/
│   └── TC1.robot
